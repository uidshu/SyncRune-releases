# SyncRune

[English](README.md) · **Русский**

**Личные финансы на твоём компьютере.**

SyncRune — приложение для личного учёта финансов в Windows. Веди счета и операции, анализируй расходы и планируй бюджет. Финансовые данные обрабатываются на твоём компьютере, без регистрации и подключения к банкам.

**1.1 Beta · Windows 10 22H2 / Windows 11 · x64**

## Скачать

[**Скачать для Windows**](https://github.com/uidshu/SyncRune-releases/releases/download/v1.1.0-beta/SyncRune-Setup.exe) · [Описание выпуска и контрольная сумма](https://github.com/uidshu/SyncRune-releases/releases/tag/v1.1.0-beta)

Запусти `SyncRune-Setup.exe`, заверши установку и открой SyncRune через меню «Пуск». Перед обновлением закрой приложение и сохрани резервную копию.

Python и Node.js не нужны. Установщик проверяет наличие WebView2 Runtime и .NET Framework 4.8.

## Возможности

- Счета, доходы, расходы и переводы.
- Аналитика расходов по категориям и периодам.
- Лимиты расходов и финансовые цели.
- Импорт CSV, TSV, TXT и XLSX; экспорт операций в CSV.
- Зашифрованные резервные копии и восстановление данных.

## Статус беты

SyncRune находится в стадии бета-тестирования. Обратная связь и сообщения об ошибках помогают повышать надёжность приложения и совместимость импорта.

Пока тестируй приложение на искусственных данных, без реальных выписок, чеков и личных документов. Храни отдельные резервные копии важных записей и не используй бету как единственное хранилище важной финансовой информации.

Установщик проверен в изолированных сценариях на компьютере разработчика и в чистой Windows 11 Sandbox. Windows 10 и другие компьютеры остаются непроверенными. Сборка не подписана цифровой подписью; автоматического обновления нет.
